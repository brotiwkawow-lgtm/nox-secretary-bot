# Nox Secretary Bot

Бот-секретарь + система сбора отзывов для клана NOX.

## Возможности

- Авто-ответ через 5 минут, если админ не ответил (текст + фото/гифка)
- Сбор отзывов по специальной ссылке
- Возможность отправить отзыв анонимно или с именем/@username
- Публикация отзывов в указанный чат/канал

## Быстрый старт (Railway)

1. Создай бота у @BotFather
2. Узнай свой ID у @userinfobot
3. Загрузи эти файлы на GitHub
4. Создай проект на railway.app
5. Подключи репозиторий
6. Добавь переменные:
   - BOT_TOKEN
   - ADMIN_ID
   - AUTO_REPLY_DELAY=300
7. Start Command: `python bot.py`

## Команды бота

### Для админа:
- `/set_text Привет! Я занят` — текст авто-ответа
- `/set_photo` → отправь фото
- `/set_gif` → отправь гифку
- `/clear_media` — убрать медиа
- `/set_reviews_chat` → перешли сообщение из чата отзывов
- `/review_link` — получить ссылку для отзывов
- `/status` — текущие настройки

### Для людей:
- Просто пишут боту → сообщение приходит админу
- Переходят по ссылке отзывов → пишут отзыв → выбирают анонимно/с именем
